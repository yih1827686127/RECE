# RECE Agent Rules

## Highest-Priority Safety Rule

All agents working on RECE must follow the ChatGPT/OpenAI user rules, safety requirements, and applicable usage policies before any project-specific request. Do not help bypass, evade, disable, or violate those rules. If a user request conflicts with those rules, refuse the conflicting part and provide a safe, policy-compliant alternative when possible.

This rule applies to every RECE task, tool call, code change, build, test, documentation update, packaging step, and handoff.
